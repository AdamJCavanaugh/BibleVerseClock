# BibleVerseClock

Shows the current time and a Bible verse based on the hour and minute. Choose between the King James Version (KJV) and World English Bible (WEB).

Inspired by ads for [Bible Clock](https://www.thebibleclock.com/). It looks like [this app](https://play.google.com/store/apps/details?id=com.codeinfaith.bibleclock&hl=en_US) may be similar, but I wanted to write my own.

The WEB text is adapted from Project Gutenberg's *The World English Bible (WEB), Complete* and reformatted as one `Book Chapter:Verse<TAB>Text` record per line to match `bibles/kjv.txt`.
